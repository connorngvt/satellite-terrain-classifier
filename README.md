# Satellite Terrain Image Classifier

A machine learning application that classifies different types of terrain from satellite images using a deep learning model, built with TensorFlow and deployed with Streamlit.


## 🚀 Live Demo

Check out the live app here:  
🔗 [Satellite Terrain Classifier](https://connorngvt-satellite-terrain-classifier-app-jw6ia0.streamlit.app)

## 🧠 How It Works

1. Upload a satellite image.
2. The model processes the image using TensorFlow.
3. It returns the predicted terrain class (e.g., green_area, desert, water, cloudy) with a confidence score.
